# AGENTS.md — docs/ 目录指引

> 本文件指导 AI Agent 在 `docs/` 目录的工作。根级规范见 [../AGENTS.md](../AGENTS.md)（单一事实源）。

## 目录作用与目标
存放本项目的**治理、研究、规划、度量、分发**文档。本项目自身按 AI Agent 项目规范运作——**所有关键决策必须落地到文档**（见 `00-决策记录.md`），不停留在对话或个人脑中。

## 文件编号规范（ADR-011）
按**功能分类 + 优先级**编号，**中文文件名**；编号越小越基础/优先。

| 区段 | 分类 | 现有文件 |
|---|---|---|
| `00–09` | 治理与决策 | `00-决策记录.md`、`01-里程碑与验收标准.md` |
| `10–19` | 研究与原则 | `10-AI辅助开发最佳实践研究报告.md`、`11-Claude-Skill构建完整指南.pdf` |
| `20–29` | 规划 | `20-改进计划.md` |
| `30–39` | 度量 | `30-度量指南.md` |
| `40–49` | 分发与部署 | `40-分发与部署指南.md` |
| `90–99` | 归档 | `90-归档/`（陈旧但留追溯） |

## 在此目录工作的规范
- **新增文档**：归入正确区段、取中文名、按规范编号；在本表登记。
- **新增/变更决策**：追加一条 ADR 到 `00-决策记录.md`（编号/日期/状态/背景/决策/理由/影响）；推翻旧决策时新增条目并把旧条标为「已废止」。
- **里程碑变化**：更新 `01-里程碑与验收标准.md` 的勾选项。
- **跨文档引用**：用相对路径 + 中文文件名；改名后用 grep 全仓更新引用。
- **语言**：中文为主（ADR-004），专有名词保留英文。
- **不在 docs 写时效性信息**（用"old patterns"或归档承载历史）。
