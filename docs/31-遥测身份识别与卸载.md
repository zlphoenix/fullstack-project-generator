# 遥测身份识别原理与卸载机制

> 配套：`docs/30-度量指南.md`（指标定义）、`telemetry/hooks/README.md`（hook 接入）、`telemetry/schema.md`（事件字段）。
> 决策依据：[ADR-013](00-决策记录.md)（进展从产物派生 + 遥测）、[ADR-017](00-决策记录.md)（工具侧 hook 自动埋点）。

## 一、每个维度"是怎么识别出来的"

一条遥测事件的关键字段及其来源：

| 维度 | 字段 | 来源 | 粒度/可靠性 |
|---|---|---|---|
| **是谁** | `actor_id` | 环境变量 `FPG_ACTOR_ID`（`~/.fpg-telemetry/env.sh`，install 时按 `--user`/`$USER` 写入） | 人；缺省 `anonymous` |
| 角色 | `actor_role` | 环境变量 `FPG_ACTOR_ROLE`（dev/product/qa/ops/pm） | 角色 |
| 哪个工具 | `tool` | hook 命令参数（`tool_hook.sh codex|claude`）或 `FPG_TOOL` | 可靠 |
| 哪个项目 | `project_id` | hook 从工具传入的 `cwd` 取目录名（可用 `FPG_PROJECT` 覆盖） | 可靠 |
| 时间/会话/回合 | `ts` / `attrs.session*` / `attrs.turn_id` | 工具 hook 的 stdin payload | 可靠 |
| **命中哪个 skill** | `skill` | **SKILL 内 emit**（`--skill <name>`）；工具 hook 无法得知，仅填工具名占位 | best-effort |
| **项目阶段/里程碑** | `phase` / `milestone` | **SKILL 内 emit**（`--phase`/`--milestone`）+ 从产物派生（PRD/sprint/PROGRESS/git） | best-effort |

### 两条腿（互补，缺一不可）
1. **工具侧 hook（可靠粗粒度）** —— `telemetry/hooks/tool_hook.sh`，由 Codex/Claude 在 `SessionStart`/`Stop` 自动触发，发 `session_start`/`turn_complete`。回答"谁、用什么工具、在哪个项目、何时、活跃多少回合"。**不依赖模型自觉。**
2. **SKILL 内 emit（best-effort 细粒度）** —— 各 `SKILL.md` 在关键节点调用 `emit.sh`，带 `--skill/--phase/--milestone/--attrs`。回答"具体哪个 skill、什么阶段、哪个 Story、AC 是否通过"。**依赖模型执行到。**

### 关键前提：环境变量必须到达"非交互 shell"
Codex/Claude 执行命令用的是**非交互 shell**——它读 `~/.zshenv`，**不读** `~/.zshrc`。
- **hook 脚本**：自身会 `source ~/.fpg-telemetry/env.sh`，所以即使没改 `~/.zshenv` 也能工作。
- **SKILL 内 emit**：跑在工具的命令 shell 里，需要 env 已在该 shell 中。因此 `install.sh --wire-env` 会向 `~/.zshenv` 写入一段**带标记的可逆块**：
  ```sh
  # >>> fpg-telemetry >>>
  [ -f ~/.fpg-telemetry/env.sh ] && source ~/.fpg-telemetry/env.sh
  # <<< fpg-telemetry <<<
  ```
  这就是为什么改完 `~/.zshrc` 没用、改 `~/.zshenv` 才生效。

> 隐私：只采流程元数据，不采代码/PII。`actor_id` 用什么由你定（可用真名或不透明 ID）。`FPG_TELEMETRY_DISABLED=1` 可随时关闭。度量用于改进，不作个人考核（[ADR-012](00-决策记录.md)）。

## 二、安装做了哪些"会留在系统里"的改动

| 改动 | 位置 | 由谁写 | 可逆 |
|---|---|---|---|
| 遥测 env 文件 | `~/.fpg-telemetry/env.sh` | install | 删除即可 |
| 非交互 shell 注入块 | `~/.zshenv`（带 `>>> fpg-telemetry >>>` 标记） | `--wire-env` | `--uninstall` 精确删除标记块 |
| Skill 软链 | `<项目>/.claude/skills/*`、`.codex/skills/*` | install | `--uninstall` 仅删指向本仓库的软链 |
| 项目公共参考软链 | `<项目>/.fpg/references` | install | `--uninstall` 删除 |
| 公共文件 | `<项目>/AGENTS.md`、`PROGRESS.md` | install（已存在则**不覆盖**） | 手动（可能含你的改动） |
| 工具 hook 配置 | `<项目>/.codex/hooks.json`、`.claude/settings.json` | `--wire-hooks`（已存在则跳过） | 手动（可能含你的改动） |

> 设计原则：**只动自己写的、带标记的内容；可能含用户改动的文件一律不自动删**——避免破坏。

## 三、卸载机制

```bash
# 预览将移除什么（不改任何东西）
bash "$FPG_HOME/scripts/install.sh" --project-dir <项目路径> --uninstall --dry-run

# 实际卸载
bash "$FPG_HOME/scripts/install.sh" --project-dir <项目路径> --uninstall
```

`--uninstall` 会**自动**：
- 从 `~/.zshenv` 移除 `>>> fpg-telemetry >>>` 标记块（精确按标记删，不碰你其它内容）。
- 删除 `<项目>/.claude/skills`、`.codex/skills` 中**指向本仓库**的 skill 软链（你自有的同名 skill 不动）。
- 删除 `<项目>/.fpg/references` 软链。

`--uninstall` **不会**自动删除（可能含你的改动，需手动）：
- 项目 `AGENTS.md` / `PROGRESS.md`（如需移除 FPG 段落请手动编辑）。
- 项目 `.codex/hooks.json` / `.claude/settings.json`（hook 配置）。
- `~/.fpg-telemetry/env.sh` 与 `telemetry/data/`（删除即彻底清除遥测数据）。

彻底停止与清除：
```bash
kill "$(cat "$FPG_HOME/telemetry/data/collector.pid")"   # 停收集器
rm -rf ~/.fpg-telemetry "$FPG_HOME/telemetry/data"        # 清 env 与数据
```

## 四、可靠验证

```bash
# 1) 非交互 shell 能拿到 env（修复的核心）
zsh -c 'echo "$FPG_HOME / $FPG_ACTOR_ID"'        # 期望非空，例如 .../generator / allen

# 2) 起收集器
(cd "$FPG_HOME/telemetry" && bun run collector &) ; sleep 1 ; curl -s localhost:10000/health

# 3) 用各工具"配置里的真实命令"模拟一次回合结束
echo '{"hook_event_name":"Stop","cwd":"<项目路径>","turn_id":"t1"}' \
  | bash "$FPG_HOME/telemetry/hooks/tool_hook.sh" codex
sleep 0.5

# 4) 确认入库且 actor_id 正确
bun -e 'const {Database}=require("bun:sqlite");
  const db=new Database("'"$FPG_HOME"'/telemetry/data/events.db",{readonly:true});
  for(const r of db.query("SELECT actor_id,tool,project_id,event_type FROM events ORDER BY ts").all()) console.log(JSON.stringify(r));'
# 期望出现：{"actor_id":"<你>","tool":"codex","project_id":"<项目>","event_type":"turn_complete"}
```
真实使用时，在工具里跑一轮，回合结束即自动入库；用 `bun run report` 出报表。
